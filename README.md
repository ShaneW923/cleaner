# Cleaner

一个给自己用的 Mac 清理工具：扫描缓存、日志和开发工具缓存，告诉你每个文件夹是什么、删了会怎样。没有代价的直接删除，有代价的移到废纸篓。

## 能做什么

- **扫描范围**：`~/Library/Caches`、`~/Library/Logs`、`~/.cache`，以及 nvm、npm、Yarn、Bun、Gradle、Cargo、Xcode DerivedData 的缓存，和 Homebrew 旧版本。结果边扫边出，可以中途停止
- **认出是谁的**：按 Bundle ID 和名字匹配已安装的 App，显示真实图标
- **按"删了会怎样"分组**，每一项带一个类型标签：

  | 分组 | 类型 | 删了会怎样 |
  |---|---|---|
  | 推荐清理 | 安装包、下载缓存、编译缓存、崩溃报告、日志 | 没有影响 |
  | 可以清理 | 网页缓存、聊天缓存、图片缓存、网络缓存、App 缓存 | 不丢数据，但有一点代价，比如打开会变慢、要重新下载 |
  | 不建议 | 系统缓存 | 系统会自己管理 |

- **看里面是什么**：读取大缓存里文件的开头，识别 App 更新安装包、网页缓存和图片视频。聊天 App 能判断就给出图片占比，判断不了就提醒"可能含聊天文件"
- **提醒**：未找到对应 App 的会写出最后修改时间；正在运行的 App 会提示先退出
- **磁盘概览**：可用空间、占用条，以及清理所选之后能多出多少
- **石头图**：每个缓存是一块石头，大小按占用算，点击选中；清掉的变成砂纹

## 怎么删

| 分组 | 删除方式 |
|---|---|
| 推荐清理 | **永久删除**，空间马上释放（Homebrew 旧版本交给 `brew cleanup`） |
| 可以清理、不建议 | **移到废纸篓**，可以放回 |

## 安全

清理时，每一项在真正删除的那一刻还要再过一遍这些检查：

- **保护名单**：鼠标悬停在某一行上点"保护"，这一项永远不会被清理。名单文件读不出来或损坏时，整个清理功能会停用
- **运行中的 App 跳过**：App 正在运行，或者判断不出是否在运行，就跳过它的缓存
- **只在允许的位置删除**：只能处理上面几个缓存位置的第一层，或固定的几个开发工具缓存路径；替身、上层文件夹（比如 `~/.nvm` 本身）一律拒绝
- **删前再核对**：文件夹已经不存在，或者比扫描时变大了很多，就跳过
- **操作日志**：每次删了什么、多大、怎么删的，都记在 `~/Library/Logs/cleaner/operations.log`
- 全选只在"推荐清理"里提供，系统缓存不会被批量勾选

## 运行

需要 macOS 和 Node.js（v20 以上）：

```bash
git clone https://github.com/ShaneW923/cleaner.git
cd cleaner
npm install
npm start
```

运行测试：

```bash
npm test
```

## 代码结构

| 文件 | 作用 |
|---|---|
| `src/locations.js` | 扫描哪些位置，以及只允许在哪里删除 |
| `src/scanner.js` | 扫描文件夹、计算大小、路径安全检查 |
| `src/cleaner.js` | 真正执行清理：保护名单、运行中、路径、大小变化这些检查，然后永久删除或移到废纸篓 |
| `src/protect.js`、`src/oplog.js` | 保护名单（读不出来就停）、操作日志 |
| `src/homebrew.js` | 通过 `brew cleanup` 处理 Homebrew 旧版本 |
| `src/apps.js` | 用 Spotlight 建立已安装 App 的索引，把文件夹匹配到 App |
| `src/advisor.js` | 判断每个文件夹的类型、分组和说明 |
| `src/contents.js` | 看文件夹里装的是什么：安装包、网页缓存、图片视频 |
| `src/main.js`、`src/preload.js` | Electron 主进程和界面之间的桥 |
| `src/renderer/` | 界面（HTML / CSS / JS），石头图在 `stones.js` |

判断逻辑和界面是分开的，改界面不用动扫描和判断规则。

## 已知限制

- 还没有 App 卸载和残留发现
- 不会帮你清空废纸篓
- 没有完全磁盘访问权限时，部分文件夹会显示"部分无权限"
- 同一个 App 的不同类型（比如安装包和网页缓存）会分成多行显示
- 还没有打包成 App，需要用 `npm start` 运行
