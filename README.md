# Cleaner

一个给自己用的 Mac 清理工具：扫描 `~/Library/Caches`，告诉你每个文件夹是什么、删了会怎样，勾选后移到废纸篓。

## 能做什么

- **扫描缓存**：几秒扫完 `~/Library/Caches`，结果边扫边出，可以中途停止
- **认出是谁的**：按 Bundle ID 和名字匹配已安装的 App，显示真实图标
- **按"删了会怎样"分组**，每一项带一个类型标签：

  | 分组 | 类型 | 删了会怎样 |
  |---|---|---|
  | 推荐清理 | 安装包、下载缓存、编译缓存、崩溃报告、日志 | 没有影响 |
  | 可以清理 | 网页缓存、聊天缓存、图片缓存、网络缓存、App 缓存 | 不丢数据，但有一点代价，比如打开会变慢、要重新下载 |
  | 不建议 | 系统缓存 | 系统会自己管理 |

- **看里面是什么**：读取大缓存里文件的开头，识别 App 更新安装包、网页缓存和图片视频。聊天 App 能判断就给出图片占比，判断不了就提醒"可能含聊天文件"
- **提醒**：未找到对应 App 的会写出最后修改时间；正在运行的 App 会提示先退出
- **磁盘概览**：可用空间、占用条，以及清理所选之后能多出多少
- **石头图**：每个缓存是一块石头，大小按占用算，点击选中；清掉的变成砂纹

## 安全

- 只会**移到废纸篓**，不会直接删除，随时可以放回原处
- 只能处理 `~/Library/Caches` 的第一层文件夹，替身和其他路径一律拒绝
- 全选只在"推荐清理"里提供，系统缓存不会被批量勾选

## 运行

需要 macOS 和 Node.js（v20 以上）：

```bash
git clone https://github.com/ShaneW923/cleaner.git
cd cleaner
npm install
npm start
```

运行测试：

```bash
npm test
```

## 代码结构

| 文件 | 作用 |
|---|---|
| `src/scanner.js` | 扫描缓存文件夹、计算大小、移到废纸篓（带路径安全检查） |
| `src/apps.js` | 用 Spotlight 建立已安装 App 的索引，把文件夹匹配到 App |
| `src/advisor.js` | 判断每个文件夹的类型、分组和说明 |
| `src/contents.js` | 看文件夹里装的是什么：安装包、网页缓存、图片视频 |
| `src/main.js`、`src/preload.js` | Electron 主进程和界面之间的桥 |
| `src/renderer/` | 界面（HTML / CSS / JS），石头图在 `stones.js` |

判断逻辑和界面是分开的，改界面不用动扫描和判断规则。

## 已知限制

- 只扫描 `~/Library/Caches`，还没有 App 卸载和残留发现
- 没有完全磁盘访问权限时，部分文件夹会显示"部分无权限"
- 同一个 App 有多个缓存文件夹时，会分成多行显示
- 还没有打包成 App，需要用 `npm start` 运行
